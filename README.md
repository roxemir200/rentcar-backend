# 🚗 Rent A Car - PFE

Application de location de voitures.

## Technologies
- Backend : Spring Boot 4.1.0 + MySQL
- Frontend : Angular
- Paiement : Stripe
- Notifications : SSE

## Installation
1. Importer `rentcar_db.sql` dans MySQL
2. Lancer `RentCarApplication.java`
3. API dispo sur `http://localhost:8089`
4. Swagger : `http://localhost:8089/swagger-ui.html`
